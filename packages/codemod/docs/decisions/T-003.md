# T-003 이름, 위치, 배포

## 맥락

v1 토큰을 쓰는 제품 코드를 v2로 옮기는 도구를 어디에 어떤 이름으로 둘지 정합니다.
의견은 이슈 #110에서 받습니다.

## 결정

`packages/codemod`에 `@sopt-mds/codemod`라는 이름으로 두고, `private: true`로 시작합니다. bin 이름은 `mds-migrate`(가칭)입니다.

`src/core`(공유 로직), `src/maps`(맵), `src/transforms`(규칙)로 나누고, 명령은 `src/cli.ts`의 표에 추가합니다.

## 검토한 대안

별도 레포에 두면 맵을 만들 때 `@sopt-mds/design-tokens`를 workspace로 읽을 수 없습니다.
bin 이름은 다른 후보와 비교하지 않았습니다. `mds-migrate`는 가칭이고, 이슈 #110에서 의견을 받습니다.

## 결과

배포는 별도 승인 후에 하고, 그 전에는 changeset을 만들지 않습니다.
컴포넌트 명령은 같은 패키지에 명령 하나를 더하는 방식으로 열어 둡니다.
