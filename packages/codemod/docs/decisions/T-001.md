# T-001 CLI 빌드와 실행 방식

## 맥락
CLI는 Node 22(CI 기준)에서 `pnpm -r build`로 빌드되고 레포 밖에서도 실행돼야 한다.
jscodeshift는 transform 파일을 경로로 받아 워커에서 `require`한다.

## 결정
다른 패키지와 같은 vite 라이브러리 모드(`rolldown-vite`)로 ES 파일을 만든다. jscodeshift와 `node:` 모듈은 번들하지 않는다.
실행 방식(T-004)은 jscodeshift `Runner` API에 빌드한 transform 파일을 넘기는 것으로 정했다. 리포트를 만들 방법은 첫 변환 규칙 전에 다시 본다.

## 검토한 대안
esbuild, tsup, tsx 런타임을 다음 후보로 두었다.
첫 후보인 vite가 조건을 모두 만족해 시도하지 않았다.

## 결과
산출물은 `dist/cli.js` 하나이고 레포 밖에서 `--help`, `--list`가 동작한다. 변환 규칙이 생기면 `vite.config.ts`의 entry에 추가한다.
Runner는 transform 로드에 실패해도 오류 0건을 돌려준다. 실행을 구현할 때 처리한 파일 수를 확인해 실패로 바꿔야 한다.
