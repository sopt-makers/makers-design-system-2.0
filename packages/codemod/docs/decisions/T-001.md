# T-001 CLI 빌드와 실행 방식

## 맥락

CLI는 CI 기준 Node 22에서 `pnpm -r build`로 빌드되고, 레포 밖에서도 실행돼야 합니다.
jscodeshift는 transform 파일을 경로로 받아 워커에서 `require`합니다.

## 결정

다른 패키지와 같은 vite 라이브러리 모드(`rolldown-vite`)로 ES 파일을 만듭니다. jscodeshift와 `node:` 모듈은 번들하지 않습니다.

실행 방식(T-004)은 jscodeshift CLI를 자식 프로세스로 실행하는 것입니다. 규칙이 파일별 결과를 JSON 한 줄씩 적으면, 부모가 그것을 읽어 요약과 종료 코드를 정합니다.

## 검토한 대안

esbuild, tsup, tsx 런타임을 다음 후보로 두었습니다. 첫 후보인 vite가 조건을 모두 만족해서 시도하지 않았습니다.

## 결과

산출물은 `dist/cli.js` 하나이고, 레포 밖에서 `--help`, `--list`가 동작합니다. 변환 규칙이 생기면 `vite.config.ts`의 entry에 추가합니다.

jscodeshift CLI는 `--fail-on-error`를 켜도 규칙 로드 실패와 없는 파일을 exit 0으로 끝냅니다. 그래서 실행을 구현할 때 부모가 규칙을 `require`로 먼저 확인하고, 처리한 파일 수를 대조합니다.
