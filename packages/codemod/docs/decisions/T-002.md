# T-002 테스트 러너

## 맥락

이 레포에는 테스트 러너가 없었습니다.
jscodeshift `defineTest`로 input/output fixture를 검증해야 합니다.

## 결정

vitest를 씁니다. 이미 쓰고 있는 vite(`rolldown-vite`)를 그대로 공유합니다.
`defineTest`가 전역 `describe/it/expect`를 쓰기 때문에 `globals: true`로 둡니다.

## 검토한 대안

jest를 다음 후보로 두었습니다. vitest가 조건을 만족해서 시도하지 않았습니다.

## 결과

더미 fixture가 통과하고, output을 일부러 틀리게 바꾸면 실패합니다.

`defineTest`는 transform을 Node `require`로 읽습니다. 그래서 transform과 그 안의 상대 import에는 `.ts` 확장자를 붙이고, Node가 지우지 못하는 문법(enum 등)은 `erasableSyntaxOnly`로 막았습니다.
