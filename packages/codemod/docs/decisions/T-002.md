# T-002 테스트 러너

## 맥락
이 레포에는 테스트 러너가 없었다.
jscodeshift `defineTest`로 input/output fixture를 검증해야 한다.

## 결정
vitest를 쓴다. 이미 쓰는 vite(`rolldown-vite`)를 그대로 공유한다.
`defineTest`가 전역 `describe/it/expect`를 쓰므로 `globals: true`로 둔다.

## 검토한 대안
jest를 다음 후보로 두었다.
vitest가 조건을 만족해 시도하지 않았다.

## 결과
더미 fixture가 통과하고 output을 틀리게 바꾸면 실패한다.
`defineTest`는 transform을 Node `require`로 읽는다. 그래서 transform과 그 안의 상대 import에는 `.ts` 확장자를 붙이고, Node가 지우지 못하는 문법(enum 등)은 `erasableSyntaxOnly`로 막는다.
