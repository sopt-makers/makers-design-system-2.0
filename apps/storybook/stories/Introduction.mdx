# Makers Design System

SOPT 사내 조직인 Makers의 디자인 시스템 2.0 버전입니다.

## 구조

- **Design Tokens** — 색상, 간격, 타이포그래피 등 시스템의 원시 값
- **Components** — `@sopt-mds/ui` 가 제공하는 React 컴포넌트

## 설치

1. 디자인 토큰, UI 컴포넌트

```bash
pnpm add @sopt-mds/ui @sopt-mds/design-tokens
```

2. Peer Dependencies

`react`와 `react-dom` 18 버전 이상이 필요합니다.

```bash
pnpm add react react-dom
```
