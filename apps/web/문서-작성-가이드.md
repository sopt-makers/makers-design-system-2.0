# 문서 작성 가이드

이 문서는 **디자이너가 직접 문서 본문을 채울 때** 보는 가이드입니다.
코드 지식 없이 **Markdown** 문법만 알면 됩니다.

---

## 1. 어디를 수정하나요?

문서 본문은 전부 아래 폴더의 `.mdx` 파일입니다.

```
apps/web/src/content/<카테고리>/<문서이름>.mdx
```

예) **Spacing** 문서 → `apps/web/src/content/foundations/spacing.mdx`

지금은 대부분 `문서 준비 중입니다.` 로 비어 있어요. **그 자리를 지우고 내용을 쓰면 됩니다.**

---

## 2. 작성하면서 바로 미리보기

저장소 루트 터미널에서:

```bash
pnpm web
```

안내되는 주소(예: `http://localhost:5173`)를 브라우저로 열어두면, **파일을 저장할 때마다 자동으로 새로고침**됩니다. 보면서 작성하세요.

---

## 3. 쓸 수 있는 문법

아래 요소는 **자동으로 디자인 시스템 스타일**이 입혀집니다.

```md
# 페이지 제목
## 섹션 제목          ← 오른쪽 목차(TOC)에 자동 등록됩니다
### 하위 섹션          ← 목차에 자동 등록됩니다

본문은 한 줄 띄우고 그냥 작성합니다.
**굵게**, `인라인 코드`, [링크 글자](https://example.com) 도 됩니다.

- 목록 항목
- 목록 항목

1. 번호 목록
2. 번호 목록

> 인용구입니다.

---
```

- **코드 블록**: 백틱 3개(```` ``` ````)로 위아래를 감쌉니다.
- **이미지**: `![설명](이미지주소)`

**지원되는 것**: 제목 `#`~`###`(3단계), 문단, **굵게**, `인라인 코드`, 코드 블록, 목록, 링크, 이미지, 인용구, 구분선(`---`).

**아직 특별 스타일이 없는 것**(필요하면 개발자에게 요청): `####` 이상 제목, 표(table), 색상 강조 박스, 기울임 등.

---

## 4. 실제 컴포넌트를 문서에 띄우기 (선택)

이 문서는 MDX라서, **실제 디자인 시스템 컴포넌트**를 문서 안에 그대로 렌더할 수 있어요.
파일 **맨 위**에 `import` 한 줄을 적고, 본문에서 태그처럼 쓰면 됩니다.

```mdx
import { ActionButton } from "@sopt-mds/ui";

## 버튼 예시

아래는 실제 동작하는 버튼입니다.

<ActionButton>눌러보세요</ActionButton>
```

> 어떤 컴포넌트가 있고 어떤 속성을 쓰는지는 Storybook에서 확인하세요: `pnpm storybook`

---

## 5. 작성 흐름 요약

1. `apps/web/src/content/...` 에서 채울 `.mdx` 파일 열기
2. `문서 준비 중입니다.` 를 지우고 내용 작성
3. `pnpm web` 으로 미리보기
4. 완료되면 저장 → 개발자에게 공유(또는 커밋)
