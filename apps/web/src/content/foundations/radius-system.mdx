# Radius System

MDS는 일관된 Radius 체계를 정의해 컴포넌트의 모서리 형태를 관리해요. 이를 통해 제품 전반의 시각적 일관성을 유지하고, 사용자에게 통일된 경험을 제공해요.

## 1. Base token

프로덕트에서 사용하는 모든 모서리 반경 값을 수치 기반으로 체계화한 원자 값들의 정의예요. 간격의 크기를 나타내는 숫자를 접미사로 표기해, 실제 px 값과 1:1로 대응되는 직관적인 구조를 가져요.

## 2. Radius System 사용 원칙

### 2-1. 토큰 외 수치 사용 금지

13px, 22px 처럼 토큰에 정의되지 않은 임의 수치는 사용하지 않아요. 반드시 정의된 size 중에서 선택해 사용해요.

### 2-2. Radius 선택 기준

컴포넌트의 크기, 인터랙션 여부, 브랜드 무드, 시각적 위계를 기준으로 값을 선택해요.

- 구분선, 이미지, 직각형 요소 › 작은 값 또는 'r0'
- 버튼, 입력창, 카드 등 기본 컴포넌트 › 중간 값
- 모달, 바텀시트, 큰 컨테이너 › 큰 값
- 칩, 뱃지, 원형 버튼 등 pill 형태 › 'full'

### 2-3. 토큰 참조 조건

Radius 토큰은 별도의 Semantic token을 정의하지 않고, Base token을 직접 참조해요. radius는 적용되는 맥락과 용처가 매우 광범위해요. 따라서 특정 의미를 부여하기보다는 수치 기반의 시스템을 유지하여 범용성을 확보했어요.
