# Spacing System

Spacing은 요소 간의 관계와 정보 구조를 전달하는 핵심 요소예요. MDS는 일관된 간격 스케일을 기반으로 여백을 관리해요. 이를 통해 디자이너와 개발자가 동일한 기준으로 레이아웃을 구성할 수 있으며, 제품 전반에서 안정적인 시각적 리듬과 일관성을 유지할 수 있어요.

## 1. Base token

프로덕트에서 사용하는 모든 여백과 간격 값을 수치 기반으로 체계화한 원자 값들의 정의예요. 간격의 크기를 나타내는 숫자를 접미사로 표기해, 실제 px 값과 1:1로 대응되는 직관적인 구조를 가져요.

## 2. Spacing System 사용 원칙

### 2-1. 토큰 외 수치 사용 금지

13px, 22px 처럼 토큰에 정의되지 않은 임의 수치는 사용하지 않아요. 반드시 정의된 size 중에서 선택해 사용해요.

### 2-2. Size 선택 기준

디바이스 환경, 요소 간의 관계, 시각적 위계를 기준으로 값을 선택해요.

- 같은 그룹 내 인접 요소 › 작은 값
- 컴포넌트 내부 패딩 › 중간 값
- 섹션 간 구분, 레이아웃 여백 › 큰 값

### 2-3. 토큰 참조 조건
Spacing 토큰은 별도의 Semantic token을 정의하지 않고, Base token을 직접 참조해요. 다양한 해상도 환경에 유연하게 대응해야 하며, 적용되는 맥락과 용처가 매우 광범위해요. 따라서 특정 의미를 부여하기보다는 수치 기반의 시스템을 유지하여 범용성을 확보해야 했어요.
