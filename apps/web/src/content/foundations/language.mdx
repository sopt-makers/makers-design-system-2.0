# Language

서비스의 모든 텍스트는 일관된 말투와 표현 원칙에 따라 작성해요. 상황과 맥락에 맞는 언어를 사용해 명확하게 전달해요.

## 1. 기본

**'해요'체**

- 특별한 이유가 없으면 '~해요'체를 사용해요.
- 안내·확인·완료 메시지, 토스트, 에러까지 모두 해당돼요.

| 지면 | 예시 |
| --- | --- |
| SOPT Playground - 멤버 | 아직 질문이 없어요. |
| SOPT Playground - 모임 | 번역에 대한 설명이 충분히 작성되었는지 확인해 주세요. |

## 2. 유머·변형

**'해요'체**

- 적절한 유머는 허용하되, 변형 표현(ex: '~슴')은 소셜 채널 혹은 프로모션성 콘텐츠에 한해 제한적으로 사용해요.

| 지면 | 예시 |
| --- | --- |
| SOPT 공식 앱 - 오늘의 습관 | 자세를 고쳐보게 되겠슴 |
| SOPT 공식 인스타그램 | SOPT 출신 현직자에게 무엇이든 물어보슴 |

## 3. 의문형

**'해요'체, '합니다'체**

- 확인을 물을 때, 해요체는 '~하시겠어요?', 합니다체는 '~하시겠습니까?'를 사용해요.
- Empty 상태, 헤더, CTA에서 사용자의 행동을 유도 및 제안할 때는 '~할까요?, ~해볼까요?, ~인가요?, ~있나요?' 형태를 권장해요.

| 지면 | 예시 |
| --- | --- |
| SOPT Playground - 커뮤니티 | 어떤 모임의 피드를 작성할까요? |
| SOPT Playground - 모임 | 번역에 대한 설명이 충분히 작성되었는지 확인해 주세요. |
| SOPT 리크루팅 페이지 | SOPT 지원에 대해 궁금한 것이 있나요? |

## 4. 위험

**낮은 위험 - '해요'체**

되돌릴 수 있고, 잘못 눌러도 잃을 게 없는 상황에 '~해요'체를 사용해요.

- 단순 안내, 알림 확인
- 되돌릴 수 있는 선택
- 정보가 사라지지 않는 화면 이동

**중간 위험 - '해요'체, '합니다'체**

작성 중인 내용이나 만들어둔 콘텐츠를 잃을 수 있는 상황이에요. 계정·개인정보처럼 무거운 건 아니지만, 한 번 더 확인이 필요한 작업이에요. 기본적으로 '~해요'체를 사용하지만, 리크루팅 페이지에서는 '~합니다'체를 사용해요.

- 저장되지 않은 변경사항이 사라질 때
- 작성 중에 페이지를 벗어나거나, 뒤로가기·취소로 입력한 내용이 날아갈 때
- 글·댓글·모임처럼 직접 만든 콘텐츠를 삭제할 때 (되돌릴 수 없더라도, 콘텐츠 단위면 여기)

**높은 위험 - '합니다'체**

계정, 개인정보, 제출, 배포처럼 신뢰·공개 결과에 직접 영향을 주는 상황이에요. 콘텐츠 하나가 아니라 계정 전체나 제출 결과가 걸려 있어요.

- 계정 삭제·탈퇴, 개인정보 변경
- 지원서 제출
- 어드민 배포

| 지면 | 상황 | 예시 |
| --- | --- | --- |
| SOPT Playground - 프로젝트 | 낮은 위험 | 프로젝트를 등록하시겠어요? |
| SOPT Playground - 모임 | 중간 위험 | 페이지를 나가시겠어요? 저장되지 않은 변경사항은 사라져요. |
| SOPT 리크루팅 페이지 | 높은 위험 | 지원서를 제출하시겠습니까? 제출한 뒤에는 수정할 수 없습니다. |
